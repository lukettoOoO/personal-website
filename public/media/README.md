# Portfolio media

Keep this folder flat. Add the files below as they become available.

## Personal and interface media

- `portrait.jpg` or `portrait.png` - portrait shown in the Paint window.
- `song.mp3` - optional song used by the visual player mockup once supplied.
- `paint-canvas.png` - optional Paint window artwork or screenshot.
- `interest-gaming.gif` - optional gaming scrapbook decoration.
- `interest-music.gif` - optional electronic music decoration.
- `interest-films.gif` - optional film decoration.
- `interest-swimming.gif` - optional swimming decoration.
- `interest-retro-tech.gif` - optional retro-computing decoration.
